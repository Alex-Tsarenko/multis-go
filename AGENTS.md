# Правила проекта

Будь немногословен, краток и всегда по существу. 

## Git

- Коммиты, `git push`, ветки, теги и pull request'ы — только по явной просьбе пользователя в текущем сообщении.
- Разрешение действует только для той просьбы, в которой оно дано, и не переносится на последующие изменения.

## Код

- Имена функций и переменных отражают ответственность, а не способ реализации.
- `Multis.Agent.Runtime` не зависит от `Multis.Agent.Providers`, `Multis.Agent.App` и UI. Архитектура и модель данных — в `specs.md`.
